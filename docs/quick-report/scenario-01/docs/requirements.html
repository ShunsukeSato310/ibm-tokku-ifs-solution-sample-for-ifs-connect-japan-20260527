クイックレポート シナリオ 1 — 要件定義書

発注残確認レポート
要件定義書

バージョン 1.0　／　作成日: 2026-05-26　／　IFS Cloud 25R2

1. 概要
ドキュメント種別クイックレポート 要件定義書
レポートID2000001
レポート名称発注残確認レポート（未着荷購買オーダ一覧）
対象システムIFS Cloud 25R2
作成者AI エージェント（IFS AI 基盤）
2. 業務背景・課題
現状の課題
  • 調達担当者が毎朝 Excel で発注残を手集計している（約30分/日）
  • 手集計のため最新データではなく、情報に遅延がある
  • 「発注残一覧画面を作りたい」という要件がアドオン開発扱いになっていた
クイックレポートによる解決策
  • IFS Cloud 標準のクイックレポート機能で代替可能
  • 開発不要・設定のみで即日稼働
  • IFS Cloud リアルタイムデータを常に最新の状態で参照
3. 要件定義

3.1 基本要件

項目内容
対象ユーザー調達担当者・調達マネージャー
目的未着荷の発注残を一覧で把握し、納期遅延リスクを早期に検知する
参照頻度毎営業日 朝（業務開始時）および随時
出力形式画面表示 ＋ Excel エクスポート

3.2 データ要件

項目内容
データソースPURCHASE_ORDER（購買オーダヘッダー）
PURCHASE_ORDER_LINE（購買オーダ明細）
SUPPLIER_INFO（仕入先マスタ）
抽出条件購買オーダ明細のステータス（OBJSTATE）＝ 'Released'（発注済み）
ソート順入庫予定日（PLANNED_RECEIPT_DATE）昇順

3.3 表示項目定義

No.列名（日本語）データソース備考
1購買オーダ番号PURCHASE_ORDER_LINE.ORDER_NO主キー
2明細番号PURCHASE_ORDER_LINE.LINE_NO主キー
3品目番号PURCHASE_ORDER_LINE.PART_NO
4品目名称PURCHASE_ORDER_LINE.DESCRIPTION
5仕入先IDPURCHASE_ORDER.VENDOR_NO
6仕入先名SUPPLIER_INFO.NAMESUPPLIER_ID で結合
7発注数量PURCHASE_ORDER_LINE.BUY_QTY_DUE
8入荷済数量固定値: 0入庫なし前提（発注残＝発注数量）
9発注残数量PURCHASE_ORDER_LINE.BUY_QTY_DUE入荷済数量が0のため発注数量と同値
10入庫予定日PURCHASE_ORDER_LINE.PLANNED_RECEIPT_DATEYYYY-MM-DD 形式
11遅延フラグ計算式PLANNED_RECEIPT_DATE < SYSDATE → '遅延'、それ以外 → '正常'
4. 画面レイアウト

IFS Cloud クイックレポート標準レイアウトを使用。カスタムレイアウト設定なし。

要素設定内容
画面タイトル発注残確認レポート（未着荷購買オーダ一覧）
レポート種別SQLStatement（SQL クイックレポート）
列幅自動（IFS Cloud 標準）
ページングIFS Cloud 標準（50件/ページ）
エクスポートExcel エクスポート（標準機能）
