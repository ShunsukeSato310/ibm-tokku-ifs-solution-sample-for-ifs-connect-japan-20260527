データモデル設計 — 拡張フィールド設計書

調達領域 拡張フィールド設計書

バージョン 1.0　／　2026-05-26　／　IFS Cloud 25R2　／　命名規則: C_ プレフィックス

1. 命名規則

C_ プレフィックスルール

IFS Cloud の標準拡張命名規則に従い、カスタムフィールドはすべて C_ で始める。これにより標準フィールドとの混在を防ぎ、バージョンアップ時の衝突リスクを排除する。カスタムテーブルも同様に C_ を付与する。

2. .entity 定義 — IFS 標準フォーマット

IFS Cloud の拡張は .entity ファイル（XMLベース）で定義します。以下は実際の IFS 標準 .entity フォーマットに準じた定義です。

SupplierInfo.entity（拡張フィールド追加）

<!-- checkout/purch/model/purch/SupplierInfo.entity (カスタム拡張部分) --> <ENTITY> <NAME>SupplierInfo</NAME> <COMPONENT>PURCH</COMPONENT> <ATTRIBUTES> <!-- ── 標準フィールド（抜粋） ── --> <ATTRIBUTE> <NAME>SupplierNo</NAME> <IS_PRIMARY_KEY>1</IS_PRIMARY_KEY> <DATATYPE>TEXT</DATATYPE> <LENGTH>20</LENGTH> </ATTRIBUTE> <ATTRIBUTE> <NAME>Name</NAME> <DATATYPE>TEXT</DATATYPE> <LENGTH>100</LENGTH> <IS_MANDATORY>1</IS_MANDATORY> </ATTRIBUTE> <!-- ── C_ カスタムフィールド ── --> <ATTRIBUTE> <NAME>C_PreferredCarrier</NAME> <DATATYPE>TEXT</DATATYPE> <LENGTH>30</LENGTH> <IS_MANDATORY>0</IS_MANDATORY> <IS_UPDATE_ALLOWED>1</IS_UPDATE_ALLOWED> </ATTRIBUTE> <ATTRIBUTE> <NAME>C_SlaDays</NAME> <DATATYPE>NUMBER</DATATYPE> <LENGTH>3</LENGTH> <IS_MANDATORY>0</IS_MANDATORY> <IS_UPDATE_ALLOWED>1</IS_UPDATE_ALLOWED> </ATTRIBUTE> </ATTRIBUTES> </ENTITY>
