エラー分析

画面に表示されたエラーのスクリーンショットを入力するだけで、AIが原因・影響範囲・対処方法を即座に分析。属人的なノウハウに頼らず問題解決時間を短縮します。

スクリーンショット入力 AI即時分析 対処手順自動生成
主な機能

スクリーンショット解析

エラー画面の画像をそのまま入力。文字認識によりエラーコード・メッセージ・コンテキストを自動抽出します。

原因特定

IFS Cloud の8,000+データモデル・エラーナレッジベースと照合し、発生原因を即座に特定します。

対処手順の生成

操作手順・設定変更・データ修正など、状況に応じた具体的な対処手順を自動生成します。

再発防止策の提案

同種のエラーが再発しないよう、設定見直しや運用ルール変更の提案も合わせて出力します。

INPUT — IFS Cloud エラー画面（スクリーンショット）
IFS Cloud 25R2 — 購買発注 / 承認処理
!
エラーが発生しました
ERROR_CODE: IFS-PUR-7421 | MODULE: PURCHASING | TIMESTAMP: 2026-05-26 14:32:07
購買発注 PO-IBM-2026-042 を承認できません。
承認者 IBM-BOB は現在の承認グループ PROC-APPROVAL-L2 に属していません。
詳細: Authorization group mismatch. User IBM-BOB not found in group PROC-APPROVAL-L2 for site IBM-TOKYO.
分析デモ — 出力（AI分析結果）

※ 分析エンジンの仕組みは秘匿情報のため非公開。入力と出力のみを示します。

AI 分析結果 — IFS-PUR-7421

エラー分類
権限設定ミス（承認グループ未登録）
影響範囲
IBM-TOKYO サイトの L2 承認が必要な発注すべて（推定 12件）
緊急度
高 — 承認フロー停止中
根本原因
ユーザー IBM-BOB が承認グループ PROC-APPROVAL-L2 に登録されていない。人事異動または初期設定漏れが考えられます。
  • 即時対応: IFS Cloud → 調達管理 → Purchase Authorization Basic Data → 「Authorization Groups」タブ → 対象グループ（PROC-APPROVAL-L2）を選択 → 下段「Authorization Group Members」に IBM-BOB を追加
  • 確認: 同グループに属すべき他ユーザーも同様に未登録でないか確認（同一バッチ処理で発生している可能性）
  • 再発防止: ユーザー登録・異動時の承認グループ設定チェックリストを運用ルールに追加
参考 — 承認グループ設定画面（Purchase Authorization Basic Data）

対応先となる IFS Cloud 標準画面の構成。ナビゲーター: 調達管理 → Purchase Authorization Basic Data → 「Authorization Groups」タブ。
