AI 分析結果 — IFS-PUR-7421 / 承認グループ未登録エラー

エラー分類
権限設定ミス（承認グループ未登録）
影響範囲
IBM-TOKYO サイトで L2 承認が必要な購買発注すべて（推定 12件 滞留中）
緊急度
高 — 承認フロー停止中
根本原因
ユーザー IBM-BOB が承認グループ PROC-APPROVAL-L2 に登録されていない。人事異動または初期設定漏れが原因と推定。
  • 即時対応: IFS Cloud 管理画面 → ユーザー設定 → IBM-BOB → 承認グループに PROC-APPROVAL-L2 を追加
  • 影響確認: 同グループに属すべき他ユーザーが未登録でないか一括確認（同一バッチで発生している可能性）
  • 滞留発注の処理: 設定修正後、滞留中の12件を順次再承認フローで処理
  • 再発防止: ユーザー登録・異動時の承認グループ設定チェックリストを運用ルールに追加
STEP 3 — 解決後の確認

対処完了後の確認ポイント

  • ✓ IBM-BOB が PROC-APPROVAL-L2 に表示されること
  • ✓ PO-IBM-2026-042 の承認処理が正常に完了すること
  • ✓ 滞留中の 12件すべてが承認可能な状態になること
  • ✓ 同じエラーコード IFS-PUR-7421 が再発しないこと
