STEP 2 — AI 分析処理（内部動作の概要）

分析エンジンの概要（詳細は非公開）

スクリーンショットからエラーコード・メッセージ・コンテキストを文字認識で抽出後、IFS Cloud 内部 API（UserHandling / AuthorizationGroupHandling 等）に直接問い合わせ、該当ユーザーの承認グループ設定・サイト設定・権限状態を横断的に確認します。単なるテキスト検索ではなく、ライブシステムの状態を参照することで高精度な原因特定を実現しています。

AI 分析結果 — 承認グループ未登録エラー

根本原因
ユーザー IBM-BOB が承認グループ PROC-APPROVAL-L2 に未登録。人事異動または初期設定漏れと推定。API確認により同グループの登録ユーザーが0名であることも判明。
  • 即時対応: IFS Cloud 管理画面 → ユーザー設定 → IBM-BOB → 承認グループに PROC-APPROVAL-L2 を追加
  • 影響確認: 同グループに属すべき他ユーザーも未登録でないか一括確認
  • 滞留処理: 設定修正後、滞留中12件を再承認フローで処理
  • 再発防止: ユーザー登録・異動時の承認グループ設定チェックリストを運用ルール化
