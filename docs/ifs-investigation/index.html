1権限体系の概要（3層モデル）

IFS Cloud の権限制御は 認証 (Authentication) → 認可 (Authorization) → データアクセス制御 (Data Access Control) の3層で構成されます。認可はサーバー側ビジネスロジックで完結しており、クライアントを改ざんしても回避できません。

⚠️ 重要: Permission Set は User に直接紐付けられるほか、Grant Structure（Permission Set の階層化）によって親子関係で管理されます。ロール設計では Grant Structure を活用することで保守性を高められます。

2Permission Set の種別と Delivery Type

種別Delivery Type説明変更可否
Core Permission SetCOREIFS が提供する標準権限。アップグレードで上書きされる変更不可
Custom Permission SetCUSTOMプロジェクトで作成したカスタム権限。永続的に保持変更可
Personal Permission SetPERS特定ユーザーへの個別付与。原則として最小限に留める変更可

3Projection と Access Level

各 Projection（OData サービス）には READ / WRITE / FULL の Access Level が設定されます。Permission Set に Projection を追加する際は必要最小限のレベルを設定することが推奨されます。
