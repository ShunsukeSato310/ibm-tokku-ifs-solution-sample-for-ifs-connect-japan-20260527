バージョン 1.0　／　作成日: 2026-05-26　／　IFS Cloud 25R2

1. 概要
ドキュメント種別ロビー 要件定義書
対象ロール調達担当者・調達マネージャー
対象システムIFS Cloud 25R2
作成者AI エージェント（IFS AI 基盤）
2. 業務背景・課題
現状の課題
  • ログイン後に発注残・遅延状況を把握するのに複数画面を確認する必要がある
  • 遅延発注・承認待ちへの対応が遅れがち
  • 月別発注トレンドの把握に別途レポートが必要
ロビーによる解決
  • ログイン直後に全情報を一画面で把握できる
  • KPI・グラフ・リストで例外を色分け表示
  • クイックリンクで頻用画面へワンクリック遷移

No.ウィジェット種別タイトルデータソース優先度
