ロビー（業務ダッシュボード）

役割ごとにカスタマイズされた業務ポータル画面。KPI・グラフ・タスク・クイックリンクを一画面に集約し、担当者が迷わず業務を開始できる環境を実現します。

  • IFS Cloud のデータモデルを熟知したAIが、役割・業務ニーズに応じたウィジェット構成を自動設計
  • KPI・グラフ・リスト・クイックリンクの組み合わせをAIが最適化。不要な情報を排除しシンプルに保つ
  • 要件整理 → XML 設計 → IFS Cloud 実機登録 → 画面エビデンス取得まで自律実行
  • 担当者は「誰向けに・何を見せたいか」を伝えるだけで、ロビー設定ファイル＋設計書が揃う
