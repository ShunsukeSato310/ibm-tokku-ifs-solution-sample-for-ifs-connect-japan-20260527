実行時間に関する補足
要因影響
IFS Cloud API レート制限過負荷時に429が返却される。リトライ間隔（デフォルト3秒）を設定して対処
エンティティのバリデーション品目マスタ等は登録時のバリデーションが多く、仕入先マスタより処理時間が長い
依存関係による直列処理発注明細は購買発注の登録完了を待って投入するため並列化不可
SaaS 環境の共有リソース他テナントの負荷状況によりレスポンスタイムが変動する場合がある
