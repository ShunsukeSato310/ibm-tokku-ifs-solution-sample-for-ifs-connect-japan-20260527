検証レポート（18,500件規模）

実測ベース推計　／　IFS Cloud 25R2 (pwojaqu-dev1) / Script-A-Rest

実測値について：IFS Cloud 実機（pwojaqu-dev1）への API レスポンスタイムを実際に計測した結果、1リクエストあたり平均 300〜400ms（GET系）を確認。Script-A-Rest のエンティティ作成は GET（デフォルト値取得）+ POST（登録）の最低2コールを要するため、これを基に推計しています。発注明細は FK 依存のため直列処理です。

要因影響度対策
FK 依存による直列処理（発注明細）大 — 全体の約55%を占めるヘッダー一括完了後に明細を別スクリプトで実行
IFS Cloud API バリデーション中 — 品目マスタ等で1コール追加必須フィールドを事前確認し無効値を排除
API レート制限（429）中 — リトライで最大6秒遅延/件スクリプトに指数バックオフリトライを実装
SaaS 共有リソースの負荷変動小〜中 — 時間帯により±50%程度業務時間外（深夜〜早朝）での実行を推奨
