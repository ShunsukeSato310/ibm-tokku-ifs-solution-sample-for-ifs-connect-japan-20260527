検証レポート（18,500件規模）

実測ベース推計　／　IFS Cloud 25R2 / Script-A-Rest

推計根拠：IFS Cloud API のレスポンスタイムを実際に計測した結果、1リクエストあたり平均 300〜400ms（GET系）を確認。Script-A-Rest のエンティティ作成は GET（デフォルト値取得）+ POST（登録）の最低2コールを要するため、これを基に推計しています。FK 非依存のエンティティ（仕入先・品目）は複数スクリプトの並列実行により大幅な時間短縮が可能です。

並列化戦略と留意点
ステージ並列化方針留意点
仕入先・品目マスタ20並列まで引き上げ可。スクリプトをデータ範囲で分割して同時実行エンティティ間に依存なし。積極的に並列化できる
購買発注ヘッダー10並列。仕入先ごとにグループ分けして並列実行同一仕入先の連続アクセスを分散させると効果的
発注明細発注ヘッダー単位で10並列。各ヘッダーの明細を独立スクリプトで処理同一ヘッダー内は順次処理。ヘッダーをまたぐ並列化は安全
入荷処理10並列。発注単位でグループ化明細投入フェーズの完了を確認してから開始
API レート制限（429）並列度が高い場合は発生しやすい指数バックオフリトライを実装。並列度を落とさず対応可能
SaaS 環境の負荷時間帯による変動あり業務時間外での実行推奨。並列度は環境に合わせて調整
