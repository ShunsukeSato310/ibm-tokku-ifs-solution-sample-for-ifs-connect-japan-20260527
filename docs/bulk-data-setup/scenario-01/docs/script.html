大量データセットアップ — スクリプト仕様書

調達・購買 データ投入
スクリプト仕様書

バージョン 1.0　／　2026-05-26　／　IFS Cloud 25R2 / Script-A-Rest

1. 概要
実行ツールScript-A-Rest（IFS Cloud 標準バッチ実行エンジン）
投入総件数185件（仕入先5 / 品目20 / 発注50 / 明細100 / 入荷30）
実行時間目安約20〜30分（環境性能による）
前提条件IFS Cloud 25R2 環境に接続可能なこと / サイト設定が完了していること
冪等性再実行時は既存データをスキップ（重複投入なし）
2. 実行順序と依存関係
順序ステップ件数依存
1仕入先マスタ登録5件なし（起点）
2品目マスタ登録20件なし（起点）
3購買発注ヘッダー登録50件仕入先マスタ
4発注明細登録100件購買発注ヘッダー + 品目マスタ
5入荷処理（一部）30件発注明細

Step 1 — 仕入先マスタ登録（抜粋）

// Script-A-Rest: SupplierHandling — 5仕入先を一括登録 ForEach supplier in suppliers_data { CreateSupplier({ "SupplierNo": supplier.no, // 例: "IBM-001" "Name": supplier.name, // 例: "IBM Japan Ltd." "Category": "SUPPLIER", "DefaultLanguage": "ja" }) WaitForCommit() } // suppliers_data = [ // { no:"IBM-001", name:"IBM Japan Ltd." }, // { no:"BOB-001", name:"Bob Components Inc." }, // { no:"ACM-001", name:"Acme Supply Co." }, // { no:"GLB-001", name:"Global Parts Ltd." }, // { no:"TKY-001", name:"Tokyo Tech Supplies" } // ]

Step 3 — 購買発注ヘッダー登録（抜粋）

// 50件の発注ヘッダーを連番で生成 For i = 1 to 50 { CreatePurchaseOrder({ "OrderNo": Format("PO-IBM-2026-{0:D3}", i), "SupplierNo": suppliers_data[i % 5].no, "AuthorizeCode": "IBM-BOB", "WantedDeliveryDate": AddDays(Today(), 30 + i), "ProjectCode": "PROJ-2026-A" }) }
3. エラーハンドリング
エラー種別対応方針
重複キーエラースキップして次レコードへ（ログに記録）
FK参照エラー依存先が未登録の場合は一時スキップ → 依存先登録後に再試行
API タイムアウト3回リトライ後にエラーログ出力・処理継続
バリデーションエラー対象レコードをスキップ・エラーCSV出力
