大量データセットアップ — 調達・購買領域

Script-A-Rest で購買データを
一括投入する

仕入先 5件・品目 20件・購買発注 50件・発注明細 100件・入荷処理 30件を自動投入するサンプルです。

185件一括投入 UUID自動生成 実画面確認済み
課題と解決
よくある課題
  • 環境リセット後のデータ再投入に2〜3日かかる
  • 手作業投入でデータ不整合が発生しやすい
  • デモ用データに実顧客名が混入するリスク
Script-A-Rest で解決
  • スクリプト1実行で185件を30分以内に投入
  • UUID・依存順序をAIが自動制御し整合性を保証
  • IBM / Bob など架空名称でデモデータを安全に作成
スクリプト構造（抜粋）
// Step 1: 仕入先マスタ登録 POST /ifsapp/projection/"SupplierHandling" { "SupplierNo": "IBM-001", "SupplierName": "IBM Japan Ltd.", "SupplierCategory": "SUPPLIER", "DefaultLanguage": "ja" } // Step 2: 購買発注ヘッダー登録（仕入先参照） POST /ifsapp/projection/"PurchaseOrderHandling" { "OrderNo": "PO-IBM-2026-001", "SupplierNo": "IBM-001", "AuthorizeCode": "IBM-BOB", "WantedDeliveryDate": "2026-06-30" } // Step 3: 発注明細登録（100件をループ処理） ForEach line in lines_data { POST /ifsapp/projection/"PurchaseOrderLineHandling" { "OrderNo": line.order_no, "PartNo": line.part_no, "BuyQty": line.qty } }
