大量データセットアップ — Script-A-Rest (TAR) スクリプト

TAR スクリプトで
購買データを一括投入

IFS Cloud の Script-A-Rest（TAR）形式スクリプトを使い、仕入先・品目・購買発注・入荷処理データ計185件を自動投入します。

TAR スクリプト CSV駆動バッチ 実機確認済み
背景
従来の課題
  • 環境リセット後のデータ再投入に2〜3日かかる
  • 手作業投入でデータ不整合が発生しやすい
  • デモ用データに実名が混入するリスク
TAR スクリプトで解決
  • スクリプト実行だけで185件を30分以内に投入
  • UUID・依存順序をスクリプトが自動制御
  • IBM / Bob など架空名称でデモデータを安全に構成
TAR スクリプト例 — 仕入先マスタ登録（CSV駆動バッチ）

AI が自動生成した Script-A-Rest（.md形式）スクリプトの抜粋です。

script.md（テンプレートスクリプト）
// 仕入先マスタ 新規登録テンプレート Get SupplierHandling.svc/SupplierSet/IfsApp.SupplierHandling.Supplier_Default() Into defaults Create SupplierHandling.svc/SupplierSet Into supplier { "SupplierNo": {%input.SupplierNo}, "Name": {%input.Name}, "SupplierCategory": "SUPPLIER", "DefaultLanguage": {%input.Language}, "CurrencyCode": {%input.Currency} } Print "Created Supplier: " + {$supplier.SupplierNo}
data.csv（投入データ）
SupplierNo,Name,Language,Currency IBM-001,IBM Japan Ltd.,ja,JPY BOB-001,Bob Components Inc.,en,USD ACM-001,Acme Supply Co.,en,USD GLB-001,Global Parts Ltd.,en,EUR TKY-001,Tokyo Tech Supplies,ja,JPY
main.md（エントリーポイント）
// CSV駆動バッチ実行 — 仕入先5件を一括登録 ExecuteCsv resources/suppliers.csv Using scripts/create_supplier.md
