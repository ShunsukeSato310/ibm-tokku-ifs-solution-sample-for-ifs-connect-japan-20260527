仕入先マスタ
FNDMIG 7ジョブ自動生成

IFS Cloud 標準の移行フレームワーク（FNDMIG）に従い、抽出・登録・更新・削除の各フェーズに必要な7本のジョブをAIが一括自動生成します。

FNDMIG標準準拠 7ジョブ自動生成
背景
従来の課題
  • 7ジョブの手動作成に半日〜1日かかっていた
  • ジョブ設定ミスによる実行時エラーが頻発していた
  • 定義書のメンテが追いつかず属人化していた
AI自動生成で解決
  • ビュー名入力だけで7ジョブを10分以内に自動作成
  • IFS標準の制約・設定ルールをAIが自動適用（失敗ゼロ）
  • 定義書（YAML形式）を自動出力・バージョン管理可能
生成フロー — ビュー名から定義書まで全自動

生成された7ジョブ一覧（対象ビュー: SUPPLIER_INFO）
EXTRACT
SUPPLIER_INFO_EXTRACT
ProcedureName: CREATE_OUTPUT_FILE
現在の仕入先データを全件抽出してファイルに出力。移行前データ確認・バックアップに使用。
INS INPUT
SUPPLIER_INS_INPUT
ProcedureName: CREATE_TABLE_FROM_FILE
登録用インプットファイル（TSV）をステージングテーブルに取り込む。ヘッダー行スキップルール自動設定。
INSERT
SUPPLIER_INS
ProcedureName: MIGRATE_SOURCE_DATA
ステージングテーブルから仕入先マスタへ新規登録（OnInsert=TRUE）。
UPD INPUT
SUPPLIER_UPD_INPUT
ProcedureName: CREATE_TABLE_FROM_FILE
更新用インプットファイルをステージングテーブルに取り込む。
UPDATE
SUPPLIER_UPD
ProcedureName: MIGRATE_SOURCE_DATA
ステージングテーブルから既存仕入先を一括更新（OnUpdate=TRUE）。
DEL INPUT
SUPPLIER_DEL_INPUT
ProcedureName: CREATE_TABLE_FROM_FILE
削除対象リストをステージングテーブルに取り込む。
DELETE
SUPPLIER_DEL
ProcedureName: MIGRATE_SOURCE_DATA
ViewNameを指定しない（MODIFY__バリデーション回避）。SourceName/WhereClauseをPATCHで設定。
