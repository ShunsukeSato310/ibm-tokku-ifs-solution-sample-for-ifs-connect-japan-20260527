★ DELジョブのViewName除外ルール

DELジョブにViewNameを設定するとIFSがExecuteSeq=10（OnModify=TRUE）を自動追加し、MODIFY__バリデーションが実行時に走って必須列エラーが発生します。AIはこのルールを自動適用し、SourceName/WhereClauseはPATCHで後から設定します。
