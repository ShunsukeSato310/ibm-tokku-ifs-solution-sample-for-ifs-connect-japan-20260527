全要件 判定一覧（20件）
No.要件（詳細）判定根拠・対応方針
1購買発注の登録・リリース・確認。仕入先・品目・数量・納期を入力しリリース→確認まで処理する。FitPurchase Order 標準機能（PurchaseOrderHandling）で全フロー対応。
2発注済み未着荷明細を一覧化し仕入先・残数・予定納期をExcelにエクスポートして日次業務で使う。Fitクイックレポートで発注残ビューを設定するだけ。SQL設定のみ、開発不要。
3入荷ごとに品質検査結果（合格/不合格/条件付き）を記録し、不合格品を返品処理フローへ誘導する。FitReceipt Inspection 標準機能で検品・判定・返品フローまで一括対応。
4購買発注・入荷実績・仕入先請求書の金額・数量を突合し差異を担当者に通知する。FitSupplier Invoice Matching 標準機能で3方向照合・差異通知まで対応。
550万円未満は部長1段階、50万円以上は部長→役員の2段階承認。不在時は代理者へ自動転送する。Config承認グループ・承認テンプレート設定で金額別多段階承認を実現。代理者設定も標準対応。
6仕入先ごとに納期遵守率・品質不良率・発注金額を集計し月次評価レポートとして出力する。FitSupplier Performance Management 標準レポートで KPI 集計・出力まで対応。
71発注に複数部門のコストセンターを明細単位で指定し、部門別原価管理レポートに反映させる。Configコストセンター設定 + C_COST_CENTER 拡張フィールドを明細に追加することで実現。
8仕入先ごとに定めたリードタイム（SLA）を超えた発注が存在する場合、担当者に自動メールを送信する。Dev標準にSLA管理機能なし。C_SLA_DAYS 拡張フィールド + IFS Event によるアラート実装が必要。
9発注リリース時に発注書PDFを自動生成し、仕入先メールアドレスへ自動送信する。FitDocument Management + Report Designer 標準機能でPDF自動生成・メール送信まで対応。
10社内ユーザーがカタログから品目を選んで発注依頼を起票し、購買担当者の承認後に発注に変換する。FitPurchase Requisition + Supplier Catalog 標準機能で依頼→承認→発注変換まで対応。
11同一品目・仕様を複数の仕入先に一括で見積依頼し、回答を比較して最適仕入先を選定・発注する。FitRequest for Quotation 標準機能で一括送付・比較・発注変換まで対応。
12発注ヘッダーにプロジェクトコードを紐付けてプロジェクト別購買コストを会計システムへ自動連携する。ConfigProject Accounting 設定 + C_PROJECT_CODE 拡張フィールドを発注ヘッダーに追加して実現。
13誰がいつ何の発注を承認したかをすべて記録し、内部監査・コンプライアンス対応のために出力できる。Dev標準承認履歴は保持期間・項目が限定的。C_PO_APPROVAL_LOG_TAB カスタムエンティティの実装が必要。
14発注品目が入庫された際に特定の受注や製造オーダに対して在庫を自動引当・予約する。FitInventory Reservation 標準機能で引当・予約・解放まで対応。
15入荷時にロット番号またはシリアル番号を付与し、払出・在庫移動・品質追跡をロット/シリアル単位で行う。
詳細分析レポート（プロセスモデル＋PL/SQL解析付き）→		FitLot/Serial Tracking 標準機能。INVENT_PART_LOT_MANAGER_API で追跡種別を管理。
16USD・EUR等の外貨で発注を作成し、入力日の為替レートで自動換算して会計仕訳を生成する。FitMulti-Currency 標準機能で外貨発注・為替換算・会計仕訳生成まで一貫対応。
17仕入先マスタに優先配送業者を設定し、発注書作成時に自動的に配送業者情報を引き継ぐ。Dev標準に配送業者マスタ連携機能なし。C_PREFERRED_CARRIER 拡張フィールド追加と画面カスタマイズが必要。
18承認グループに設定した金額上限を超える発注が登録された場合、承認者に警告を表示し上位者へ転送する。Config承認グループの Maximum Amount 設定で自動警告・上位転送を実現。設定のみ。
19標準支払条件とは別に自社独自の支払条件コード体系を持ち、仕入先別に設定・管理する。Dev標準支払条件では自社コード体系に対応不可。C_PAYMENT_TERMS 拡張コードテーブルの実装が必要。
20年次・期次の棚卸で全品目の現物数を記録しシステム在庫との差異を自動計算して差異仕訳を生成する。FitPhysical Inventory 標準機能で棚卸リスト作成・差異計算・仕訳生成まで対応。
