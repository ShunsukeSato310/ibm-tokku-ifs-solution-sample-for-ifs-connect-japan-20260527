1. 要件定義
要件No.15
要件品目のロット・シリアル番号管理
詳細入荷時にロット番号またはシリアル番号を付与し、払出・在庫移動・品質追跡をロット/シリアル単位で行う。不良ロットが発生した場合は影響範囲を即座に追跡できる。
最終判定Fit — IFS Cloud 標準機能で完全対応可能。開発不要。
